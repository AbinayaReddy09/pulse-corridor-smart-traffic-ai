# Pulse Corridor – Smart Traffic AI

An IEEE hackathon project developed for emergency vehicle prioritization and smart traffic management.

## Features
- Real-time traffic visualization
- Ambulance priority handling
- Adaptive signal simulation
- Interactive control panel
- Smart city traffic flow concept

## Technologies Used
- HTML
- CSS
- JavaScript
- Three.js
- Leaflet.js

## Project Overview
This project simulates a smart traffic management system that prioritizes emergency vehicles and visualizes live traffic flow in an interactive interface.
